# Knock U Back
A simple mod makes snowballs and eggs able to knock Players back.

### Commands
```
/knockuback enabled set true
```
Enable the mod (enabled by default)

```
/knockuback allowCombo set true
```
Enable combo to hit player multiple times within 20 ticks (enabled by default)

```
/knockuback comboTick set <int number>
```
Set the invulnable duration (to eggs and snowballs) after being hit.
